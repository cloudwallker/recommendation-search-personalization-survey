# 阅读路线：推荐、搜索与个性化

本路线从推荐流水线、训练目标与评价协议逐步进入具体研究问题。先完成六步基础，再按兴趣选一个分支；练习以阅读、画图和笔算为主。

## 六步基础路线

1. **推荐流水线与反馈。** 读综述前两节，画“百万物品→召回→排序→重排→曝光→反馈”。给一个未点击物品列出三种原因，解释为何它不能直接当成负喜好。成果：一页任务和数据定义。
2. **BPR与嵌入。** 读[BPR原论文](https://arxiv.org/abs/1205.2618)，手算两组正负评分损失。区分排序目标、预测概率和用户满意度。成果：一个完整符号表与数值例子。
3. **序列与图。** 读[SASRec](https://arxiv.org/abs/1808.09781)与[LightGCN](https://arxiv.org/abs/2002.02126)的方法图。用五次行为画因果注意力；用两个用户三个物品手工聚合一层。成果：说明“时间顺序”与“关系传播”分别提供什么信息。
4. **评价。** 手算Recall@3、Precision@3、MRR和二元NDCG@3，检查全候选与采样负例的不同。成果：一页评价协议，包含切分、候选集、K值、组别、随机种子和指标方向。
5. **大模型离线增强。** 读[LLM-ESR](../papers/P321.md)与[Large Language Model Enhanced Recommender Systems: A Survey](../papers/P294.md)综述，画出生成语义、表征训练、在线服务三阶段。成果：指出哪里调用大模型、哪里不调用，并讨论一个语义噪声反例。
6. **生成式ID。** 读[TIGER](https://arxiv.org/abs/2305.05065)再读[GloRank](../papers/P197.md)。给三个物品设计两层toy语义ID，解释共享语义、唯一性和合法候选限制。成果：比较召回生成与重排生成的输入输出。

## 四篇核心论文怎样精读

| 论文 | 页码路线 | 阅读产出 |
|---|---|---|
| [Agent4Ranking](https://arxiv.org/pdf/2312.15450) | 第3–4页框架与改写，第6–7页MMoE和损失，第8–10页评价 | 用同一意图写两个查询，解释模型一致性约束；指出模拟角色不是实测群体 |
| [CAGED](https://arxiv.org/pdf/2510.04502) | 第3页因果图，第4页ELBO，第5页动量和训练，第6–7页组别评价 | 画混杂路径；区分因果假设、变分近似、真实无偏保证；比较热门和冷门一行结果 |
| [GloRank](https://arxiv.org/pdf/2604.25291) | 第3页局部/全局标签，第4–5页token与训练，第6–8页实验 | 改变候选顺序，说明局部编号怎样改变而全局ID不变；列出合法输出机制 |
| [MuSeR](https://arxiv.org/pdf/2609.23677) | 第3页压缩，第4–5页兴趣与部署，第6–8页评价 | 手算压缩长度，画缓存与在线刷新；分别写公开长度50与工业超长历史能支持什么结论 |

## 基础完成后选一个分支

- **序列效率：** [SIGMA](../papers/P317.md) → [BlossomRec](../papers/P244.md) → [MuSeR](../papers/P191.md)。每篇分别填训练时间、推断时间、内存、序列长度和精度，别把不同硬件的速度直接排序。
- **语义与长尾：** [LLM-ESR](../papers/P321.md) → [IADSR](../papers/P269.md) → [H2Rec](../papers/P202.md)。每篇说明协同信号与语义信号如何对齐，以及哪些物品可能受损。
- **跨域与多场景：** [Scenario-Wise Rec](../papers/P266.md) → [SDSP](../papers/P286.md) → [LLM4CDSR](../papers/P300.md) → [AutoIFS](../papers/P251.md)。重点找负迁移、信息流和统一评价的定义。
- **生成推荐后训练：** TIGER → [GloRank](../papers/P197.md) → [HRPO](../papers/P201.md) → [GFlowGR](../papers/P222.md)。先分清单物品、列表、集合目标，再讨论信用分配和奖励。
- **个性化搜索：** [Agent4Ranking](../papers/P277.md) → [PBR](../papers/P253.md) → [PDR](../papers/P226.md)。区分查询表达、用户历史、探索停止和报告定制，不把通用问答成绩替代个性化效果。

## 整理方法卡与研究假设

先完成一篇主论文方法卡：任务、假设、模型图、一个核心公式和一个小例子。再补一篇经典与一篇相关研究，写两页比较，明确数据、预算和评价差别。最后提出一个可验证的问题，例如“在固定召回预算下，压缩是否更容易丢掉低频兴趣？”，列出相应对照和失败判据。

如果没有实验，材料应明确是阅读理解和研究假设。建议避免宽泛地说“用LLM提升推荐”，具体说明增强哪个阶段、预期解决哪种错误、增加哪些成本，以及什么结果会推翻假设。教程、预印本与正式论文也应分开引用，尤其Agent4Ranking、GloRank和MuSeR的状态需按公开版本和正式出版记录核验。
