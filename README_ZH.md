## 从哪里开始

正文、阅读指南和按主题组织的论文解读使用**中文**，英文首页提供项目范围与导航。无需安装软件，可直接阅读；公式适合在支持数学排版的 Markdown 平台上查看。

1. 按[阅读指南](<%E7%BB%BC%E8%BF%B0.md#reading-guide>)补齐前置知识，完成小型手算练习。
2. 阅读[领域综述](<%E7%BB%BC%E8%BF%B0.md>)，建立问题、方法、公式和局限之间的联系。
3. 对比[代表与前沿研究](<%E7%BB%BC%E8%BF%B0.md#representative-research>)，通过[论文目录](<%E8%AE%BA%E6%96%87%E8%A7%A3%E8%AF%BB/README.md>)进入单篇按主题组织的论文解读，核对公开原始来源。

本仓库按主题组织的论文解读的证据级别为：全文相关部分已核对 8 篇，摘要或公开简介已核对 64 篇，仅题名 24 篇。全文级别表示核对了相关部分，不表示全篇精读；摘要和题名级别不支持未经核验的方法细节或实验结论。

核验截至 **2026-10-02**。这是一份持续完善的文献选读综述，覆盖范围不等同于穷尽式系统综述。索引年份、预印本版本与正式发表日期可能不同，具体以论文解读及原始来源的说明为准。不同领域仓库有交叉收录，跨仓库数量不能直接相加为独立论文总数。

## 来源与勘误

内容为教学性综述和方法解释，链接至原论文与官方发表页面；论文题名与研究贡献归其作者。通过公开来源链接查阅原文。引用数值或理论结论时，应同时核对所引版本、实验条件和定理假设。勘误请提供题名、版本及支持来源。
